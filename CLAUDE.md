# Instructions projet

## Workflow de publication

- **Passer toute modification directement en production.**
  Concrètement : éditer les fichiers (notamment `site/`), committer et
  publier directement sur `main`, ce qui déclenche le déploiement
  GitHub Pages. Pas besoin de créer une branche de fonctionnalité ni
  d'attendre une relecture par pull request — l'autorisation est
  permanente (demandée par le propriétaire du dépôt).
